# Mnemo

**Mnemo** — веб-приложение для интервального повторения знаний, вдохновлённое Anki, но с более современным интерфейсом, удобной работой с колодами и перспективой развития AI-функций.

Проект создаётся как fullstack-приложение на Nuxt: фронтенд, серверные API-роуты, авторизация и работа с базой данных находятся в одном репозитории.

---

## Основная идея

Пользователь создаёт колоды, добавляет в них карточки и повторяет материал по интервальной системе.

Примеры сценариев:

- изучение иностранных слов;
- подготовка к собеседованиям;
- запоминание терминов;
- личная база знаний.

---

## Возможности

Текущий MVP-фокус:

- регистрация и авторизация пользователя;
- список пользовательских колод;
- создание и редактирование колод;
- создание и редактирование карточек;
- просмотр карточек внутри колоды;
- подготовка к реализации review session;
- базовая модель интервального повторения.

Планируемые возможности:

- повторение карточек по алгоритму spaced repetition;
- статистика по колодам;
- история повторений;
- публичные колоды;
- импорт и экспорт колод;
- AI-проверка ответов;
- голосовые ответы;
- подписочная модель;
- teacher/classroom mode.
