| Низкий | Шрифты и палитра | Глобальный `* { font-family }`, отдельный градиент страницы входа и самостоятельная палитра preview — точки дальнейшей унификации. Не все уникальные значения полезно превращать в глобальные токены. |

Три `!important` оставлены в адаптерах autofill и scrollbar редактора:
их удаление без браузерной проверки может вернуть стили браузера/библиотеки.
Миксины убирают дублирование исходников, но при включении в разные scoped-компоненты
CSS всё равно генерируется для каждого scope. Это не обещание аналогичного уменьшения bundle.

## Организация новых стилей

`global.scss` подключается один раз через Nuxt. В автоматически подключаемых
`_vars.scss` и `_mixins.scss` не должно быть CSS, генерируемого на верхнем уровне.
Общие миксины подключаются явно через `@use` в нужном компоненте; его компоновка
остаётся локальной. Адаптивные изменения должны содержать только отличия от базы.
Внутренние варианты компонентов задаются параметрами, а не внешними `:deep`-патчами.
